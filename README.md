# 三目並べ（二人用ミニゲーム）

ブラウザで遊べる、二人用の三目並べ（○×）です。追加ライブラリやビルドツールは不要で、`index.html` を開くだけでプレイできます。

## 機能

- 同一画面でのローカル対戦（Player X vs Player O）
- 縦・横・斜めの勝利判定
- 勝利ラインのハイライト表示
- 引き分け判定
- セッション内スコア記録（ページをリロードするとリセット）
- スマホでもタップしやすいレスポンシブUI

## 遊び方

1. `index.html` をブラウザで開く
2. Player X（先手）と Player O（後手）が交互にマスをクリックする
3. 縦・横・斜めのいずれかで3つ揃えた方の勝ち
4. 9マスすべて埋まって勝者がいない場合は引き分け
5. 「もう一度プレイ」ボタンで盤面をリセット（スコアは維持）

## 起動方法

ビルドやサーバー起動は不要です。ファイルを直接開いてください。

```bash
# 例: Windows
start index.html

# 例: macOS
open index.html
```

または、エクスプローラー / Finder から `index.html` をダブルクリックしてブラウザで開きます。

## ルール

| 項目 | 内容 |
|------|------|
| 盤面 | 3×3 マス |
| プレイヤー | Player X（先手） / Player O（後手） |
| 勝利条件 | 縦・横・斜めのいずれかで3つ揃える |
| 引き分け | 9マス埋まって勝者なし |
| 操作 | 空いているマスをクリック / タップ |
